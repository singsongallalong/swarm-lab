# C: critique

**Most important fix: slim the sleeves.** The arms are still full-width blocks with ridged cuffs, so from the ARPG and shoulder views the upper body is a broad, dark square. Cut the sleeve width substantially and drop the shoulder ridges. Nothing should sit proud at the shoulder.

- **What works:** the skirt. It is the only true A-line or bell in the wave: angled panels flare from the hip, and a red glowing hem rim catches the eye. It looks like a dress, and it holds together on the slim avatar as well.
- **Visibility:** it is nearly all black, and from the top-down view only the hem glow separates it from the ground. Add a lighter ash-grey value to the bodice, sash or stole, and run one bolder magma seam up a skirt panel toward the waist so the red "cracks run through it" rather than only rimming it.
- **Sulphur:** absent apart from the face. A small sulphur clasp or gem at the waist would add a focal point.
- **Helm:** a tall, plain block. Give it a finer crest or veil so it reads as a headpiece rather than a hat.
- **Parts:** spend them on the skirt and the colour accents. The current count looks lean.
